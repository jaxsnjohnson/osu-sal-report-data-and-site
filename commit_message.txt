⚡ Bolt: Optimize exactByDate Map allocation

💡 What: Replaced the intermediate array map allocation `new Map((exactMetrics.points || []).map(...))` with a manual `for` loop and `.set()` calls when initializing `exactByDate`.
🎯 Why: Creating an intermediate array (by mapping over `exactMetrics.points`) just to initialize a `Map` creates unnecessary object allocations (`[date, point]` arrays) and subsequent garbage collection overhead.
📊 Impact: Reduces memory footprint and garbage collection pressure during the hot path of building historical charts.
🔬 Measurement: Run `./run_benchmark.sh` to ensure correctness hasn't regressed, and observe slightly faster rendering in the frontend when processing large historical datasets.
