🚨 Severity: HIGH
💡 Vulnerability: DOM XSS via unescaped string injection in array map inside `innerHTML`. The `renderSuggestedSearches` method mapped over an array and interpolated the `term` directly into button content and `onclick` inline event handlers without any sanitization.
🎯 Impact: While the current array is hardcoded to safe strings, if the array ever became dynamic (e.g. pulled from user search history or URL params), it would immediately introduce a critical DOM XSS vulnerability.
🔧 Fix: Wrapped the `term` interpolation inside the `onclick` attribute with `escapeHtmlAttr(escapeForSingleQuote(term))` and the text content with `escapeHtml(term)`.
✅ Verification: Ran Playwright test script verifying payload properly escaped. Tests run cleanly.
